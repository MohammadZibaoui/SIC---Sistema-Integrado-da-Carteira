# SIC---Sistema-Integrado-da-Carteira

Este repositório contém o MVP do SIC (Sistema Integrado da Carteira de Projetos de Mineração), desenvolvido para a disciplina 'Sprint: Gestão Ágil de Projetos e Produtos' da Pós-Graduação em Engenharia de Software da PUC-RJ.

**Objetivo do Sistema**
O SIC busca centralizar a gestão da carteira de projetos, padronizando cadastros, facilitando importações de cronogramas e disponibilizando dashboards gerenciais para reuniões de rotina e de performance.

**Stakeholders e Usuários**
  - Clientes: Diretoria de Projetos, Gerência de Planejamento, Áreas de interface externas à Diretoria de Projetos.
  - Usuários finais: Gerentes de Projetos, Analistas de Planejamento, Diretores.
  - Stakeholders adicionais: TI (infraestrutura), áreas de compliance e financeiro.

**Time Scrum (6 pessoas)**
  - Product Owner – Especialista em gestão de portfólio de projetos
  - Scrum Master – Especialista em gestão de projetos
  - Desenvolvimento (3) – Full Stack, Frontend e UX/UI Designer
  - Consultor - Engenheiro especialista em projetos de mineração.

**Funcionalidades do MVP**
  - Cadastro de projetos
  - Cadastro de equipe por projeto
  - Cadastro de usuários com perfis de acesso
  - Menus dinâmicos de acordo com perfil do usuário
  - Estrutura inicial para dashboards

**Funcionalidades futuras (próximos incrementos):**
  - Importação de cronogramas em Excel
  - Cadastro de códigos padrão de cronograma
  - Dashboards consolidados e analíticos
